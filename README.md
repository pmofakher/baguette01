# باگت (Baguette) — MVP اندروید

«باگ ولخرجیت رو پیدا کن» — Flutter • Riverpod • go_router • SQLite + SQLCipher • Keystore

## راه‌اندازی
1. پوشه‌ی `android/` را باید Flutter بسازد: `bash tool/setup_android.sh`
2. (اختیاری) فونت Yekan Bakh را در `assets/fonts/` بگذار و بلوک fonts در `pubspec.yaml` را از کامنت دربیاور.
3. `flutter run`

## داخل MVP
- Splash + خوش‌آمد، خانه (درآمد/خرج/تراز، پول قابل خرج روزانه، باگ‌های ولخرجی، آخرین تراکنش‌ها)
- **ورود خودکار پیامک‌های بانکی (نسخه ۰.۲):**
  - خواندن و تحلیل خودکار پیامک‌های بانکی ایران (ملت، ملی، سامان، بلوبانک، رسالت، پاسارگاد و...)
  - تشخیص دقیق دخل یا خرج، مبلغ ریال/تومان و استخراج ۴ رقم کارت
  - ثبت تراکنش با تاریخ دقیق پیامک و قرارگیری در ماه مالی متناظر
  - باقی ماندن دسته به صورت خالی (Blank) جهت انتخاب سریع توسط کاربر با ۱ کلیک
  - جلوگیری از ثبت تکراری پیامک‌ها با جدول `imported_sms`
- تراکنش: دخل / خرج / انتقال بین حساب‌ها، تاریخ شمسی، اهمیت خرج (واجب/غیرضروری/لذت)، خرج ثابت
- دسته‌ها (قابل ویرایش) + بودجه ماهانه هر دسته + تخمین خرج پایان ماه
- گزارش: خلاصه ماه، مقایسه با ماه قبل، نمودار دسته‌ها، روند ۶ ماه، سهم خرج غیرضروری، نشتی‌ها
- دارایی‌ها، بدهکاری، طلبکاری و ارزش خالص
- تنظیمات: تومان/ریال، شروع ماه مالی، حساب‌ها، پشتیبان JSON (خروجی/بازیابی)

## تشخیص نشتی
دسته‌ای «نشتی» است اگر (۱) از بودجه‌اش گذشته، یا (۲) خرجش ≥ ۱.۳ برابر میانگین ۳ ماه قبل و حداقل ۵۰٬۰۰۰ تومان بیشتر باشد.

## بعداً (خارج از MVP)
FastAPI + PostgreSQL، sync با change-log و E2EE (ستون‌های uuid/updated_at/deleted آماده‌اند)، منتور هوش مصنوعی.
